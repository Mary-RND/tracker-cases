# Брендбук · TaskAPI

## Идея
«Документация как продукт»: тёмная консоль, моноширинный код, аккуратные бейджи методов. Ощущение Swagger/Postman, но проще.

## Логотип
`logo.svg` — фигурные скобки с точкой. Фиолетовый + лайм.

## Палитра
| Токен | HEX | Применение |
|---|---|---|
| `--night` | `#0C0D12` | фон консоли |
| `--panel` | `#15171F` | панели |
| `--violet` | `#8B5CF6` | бренд, POST |
| `--lime` | `#A3E635` | успех, 200 |
| `--sky` | `#38BDF8` | GET |
| `--amber` | `#F59E0B` | PATCH |
| `--red` | `#EF4444` | DELETE, ошибки |
| `--text` | `#E5E7EB` | основной текст |

## Типографика
- Код и ответы: `JetBrains Mono`, 12.5 px.
- Заголовки: `Inter` 700.
- Бейджи методов — uppercase, 10 px, 800.

## Компоненты
- **Method badge** — цвет по методу, фиксированная ширина 62 px.
- **Response block** — тёмный фон, подсветка ключей и строк.
- **Status chip** — 2xx лайм, 4xx янтарь, 5xx красный.
- **Test row** — галочка/крест + название проверки.
