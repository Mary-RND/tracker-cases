Модель данных

Поля, типы и ограничения

Task

id: integer, read-only
title: string, 3–120, required
description: string, ≤ 1000
status: enum(todo|progress|review|done)
priority: enum(low|mid|high)
author: string, read-only
createdAt: ISO date, read-only

Comment

id: integer
taskId: integer
text: string, 1–500, required
author: string
at: ISO date

Переходы статусов

todo → progress
progress → review
review → done
review → progress (возврат)
todo → done запрещён (422)

Права

admin: всё
member: create / patch / comment
viewer: только GET
мутации → 403
Реализация в браузере повторяет контракт, чтобы клиент и сервер договорились до написания кода. В боевой версии — Java/Spring Boot, PostgreSQL, JWT.
