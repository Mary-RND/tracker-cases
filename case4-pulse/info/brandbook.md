# Брендбук · Pulse

## Идея
«Ритм команды»: тёмная графитовая база, один яркий акцент, крупные цифры. Интерфейс похож на пульт, а не на документ.

## Логотип
`logo.svg` — пульс в квадрате. Акцент — коралловый.

## Палитра
| Токен | HEX | Применение |
|---|---|---|
| `--graphite` | `#15171C` | фон сайдбара, заголовки |
| `--slate` | `#23262E` | тёмные панели |
| `--coral` | `#FF5A5F` | акцент, просрочка, CTA |
| `--aqua` | `#2DD4BF` | выполнено |
| `--amber` | `#FBBF24` | в работе, предупреждение |
| `--paper` | `#F7F7F8` | фон контента |
| `--line` | `#E6E6EA` | границы |

## Типографика
- `Space Grotesk` / `Manrope` для заголовков, 700.
- `Inter` для текста.
- Цифры — табличные, крупно (28–36 px) в KPI.

## Форма
- Радиус 12 px, кнопки 8 px.
- Тени минимальные, акцент — за счёт контраста.
- WIP-лимит показан как «3 / 5» рядом с колонкой.

## Тон
Коротко и по делу: «5 задач, 2 просрочены». Без воды.
