# Брендбук · FieldOps

## Идея
«Штаб и поле». Интерфейс должен читаться на солнце с телефона в перчатке: крупные кнопки, высокий контраст, минимум мелкого текста.

## Логотип
`logo.svg` — пин локации с галочкой. Тёмно-синий + оранжевый сигнал.

## Палитра
| Токен | HEX | Применение |
|---|---|---|
| `--navy` | `#0F2742` | основной текст, шапка |
| `--blue` | `#1D4ED8` | действия диспетчера |
| `--sky` | `#3B82F6` | ссылки, акценты |
| `--orange` | `#F97316` | срочность, выезд |
| `--green` | `#16A34A` | выполнено, подписано |
| `--red` | `#DC2626` | SLA-просрочка |
| `--paper` | `#F1F5F9` | фон |
| `--card` | `#FFFFFF` | карточки |

## Типографика
- `Manrope` 700–800 для заголовков и цифр.
- `Inter` 400–600 для текста.
- Минимальный размер текста в мобильной версии — 12 px, кнопки — 44 px по высоте.

## Компоненты
- **Статус-пилюля** с точкой и текстом, не только цветом (доступность).
- **SLA-таймер** — моноширинные цифры, красный при просрочке.
- **Чек-лист** — крупные чекбоксы 24 px, зачёркивание выполненного.
- **Карточка выезда** — адрес, слот, клиент, кнопка «На объект».

## Тон
Инструктивный: «Отметьте все пункты, чтобы закрыть заявку». Без оценок и эмоций.
